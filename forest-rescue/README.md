# Forest Run

The notebook pages describe foreground/background sprites for rocks, logs, small objects, birds and trees; obstacle placement and movement; joystick control; collision tests; and a bear that moves randomly. One earlier page adds a title screen, forest scene, treasure score, and hazards.

This reconstruction turns that partial design into a compact top-down action game: collect eight treasures while navigating the documented obstacles and evading an increasingly fast, semi-random bear. Trees, rocks, logs, treasure, the player and bear now use custom C64-scale pixel sprites. An original, bright SID-inspired loop and synthesized collection, damage and victory effects begin after the first key press; `M` mutes them.
