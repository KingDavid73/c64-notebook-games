# C64 Utility Suite

These pages describe a personal C64 productivity and learning suite: disk utilities, a character editor, a sprite editor, sound/music tools, small games, and educational programs. They are a separate software project, not part of Doximodius or Insect Attack.

The browser page now includes three playable reconstructions: the documented four-octave Organ, a generated Labyrinth, and a seven-day Lemonade stand simulation. The notebook supplies the organ's core controls and names the two games; their missing rules and presentation are clearly treated as period-appropriate gap-filling rather than recovered source.
