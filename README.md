# Michael King's C64 Notebook Games

Playable browser reconstructions of games and tools from a C64-era notebook. Each project is self-contained and uses dependency-free HTML, CSS, and JavaScript.

- `insect-attack/` — playable arcade reconstruction.
- `doximodius-rpg/` — playable compact RPG reconstructed from the Sir Bedivere narrative, adventure map, rules, monsters, spells, and treasure notes.
- `forest-rescue/` — playable action reconstruction using the forest sprite and obstacle notes.
- `c64-utility-suite/` — preserved design catalog for the disk, character, sprite, sound, game, and educational utilities.

The original notebook photographs and generated contact sheets are intentionally excluded from this public repository. `NOTEBOOK-NOTES.md` summarizes the designs and explains why the material did not support a separate spaceship game.

Open the root `index.html` to launch the collection.
